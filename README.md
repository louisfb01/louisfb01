## About Me

Hi, I am Louis.

I build, teach, and explain practical AI engineering: LLM products, RAG, agents, evaluation, deployment, and the unglamorous reliability work that turns demos into systems people can actually use.

I am the CTO and co-founder of [Towards AI](https://towardsai.net/), where we create AI engineering courses, run corporate training, and help teams ship useful AI products. Before going full-time on Towards AI, I was doing a PhD at Mila and Polytechnique Montreal.

I also create [What's AI](https://www.youtube.com/@whatsai), a YouTube channel I have been building since 2020, write the [newsletter](https://louisbouchard.substack.com/), and co-authored the bestselling [Building LLMs for Production](https://amzn.to/4bqYU9b). I speak about AI engineering at conferences and events including AIE and UpHill.

My bias is simple: start with the simplest system that can work, add agents only when autonomy is actually useful, and evaluate before real users do it for you.
